# FoodHub

FoodHub is a web application for browsing and searching for meals.

## Features

- Browse meals
- Search for meals
- View meal details

## Technologies

- HTML
- CSS
- Bootstrap
- JavaScript

## Live Demo

[FoodHub – Live Demo](https://finalprojectjavascriptprogram.netlify.app/)

## About the Project

The main goal of FoodHub is to provide users with a simple way to browse meals.

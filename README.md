# FoodHub

FoodHub is a web project I made as a practice exam for the JavaScript Web Development Program at Advance Academy.

## Features

- Browse meals
- Search for meals
- View meal details

## Technologies

- HTML
- CSS
- Bootstrap
- JavaScript

## Live Demo

[FoodHub – Live Demo](https://finalprojectjavascriptprogram.netlify.app/)

## About the Project

The main goal of FoodHub is to provide users with a simple way to browse meals.

## Development

Visual Studio Code was used during development.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if you don't already have it.
4. Right-click index.html and select Open with Live Server.
